# CS 4730 PICO-8 gallery

This folder is ready to be placed at `https://uvacs.games/pico-8/`.
The gallery URL is `https://uvacs.games/pico-8/index.html`.

## Add games

1. Put student cartridges directly in `f26/`, named `gamename-lastname-firstname.p8`.
2. Run `python3 build_gallery.py` from this folder (requires the full desktop PICO-8 application).
3. Upload `index.html`, `gallery.css`, and the entire `f26/` directory to the server's `pico-8/` directory.

On this Mac the builder automatically finds the installed PICO-8. Elsewhere use:

```sh
python3 build_gallery.py --pico8 "/path/to/pico8"
```

Run the builder and upload the updated files each time submissions change. A static web page cannot enumerate a server directory or run raw `.p8` cartridges on its own. No server-side software, database, CDN, or student accounts are required.

## Names

`space_garden-smith-jane.p8` becomes **Space Garden**, by **Jane Smith**.
The last two hyphens separate last and first names; earlier hyphens belong to the game title. Use underscores for spaces, including inside compound designer names. Existing mixed capitalization is preserved; all-lowercase names are title-cased. A concatenated name like `spacegarden` cannot automatically become `Space Garden`.

Games are sorted by title, ignoring case and accents, then by designer. Files with invalid names stop the build with an explanation. Only `.p8` files directly inside `f26/` are included. Each must be a self-contained cartridge; multi-cartridge games or external includes need separate export handling.

## Players

The builder exports every cartridge using the official PICO-8 HTML player into `f26/players/<filename>/`. The gallery embeds that player with its own play button, touch controls, menu, and fullscreen control. A full-window link is also provided. Keyboard and gamepad input are handled by PICO-8; press a controller button after starting the game if the browser has not detected it. Controller/browser compatibility should be checked on classroom equipment.

Saved cartridge labels appear behind the player’s play button. If a submission has no label, the builder supplies a plain background in a temporary copy so export still works; the original `.p8` is unchanged.

Players load lazily as students scroll. Pause one game before starting another if it is still playing audio. Refreshing or leaving a player may reset game progress.

The empty gallery contains no invented student submissions. Deleted cartridges disappear from the next generated index; previously exported folders are retained, so remove those obsolete folders separately if their old URLs must stop working.

To preview locally, run `python3 -m http.server 8000` from the parent folder and open `http://localhost:8000/pico-8/index.html`.

Edit `gallery-template.html` and `gallery.css` to change the gallery; `index.html` is regenerated by the builder. Keep the builder, template, and this README locally; the server only needs the files listed in step 3.
